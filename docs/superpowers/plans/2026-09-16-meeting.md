# LearnThrive Meeting Implementation Plan

**Goal:** Build and locally test an isolated, branded two-person native WebRTC prototype.

**Architecture:** React manages media/UI, Socket.IO relays signalling, Express stores ephemeral rooms. Vite provides one browser origin.

**Tech Stack:** React, TypeScript, Vite, Express, Socket.IO, WebRTC, Vitest, Playwright.

**Spec:** ../specs/2026-09-16-meeting-design.md and the user's supplied brief.

## Constraints

All writes in this project. No deployment, no changes to marketing site, no database or additional meeting features. Keep credentials out of source.

## Tasks

- [x] Set up independent configuration and shared typed protocol.
- [x] Test room entry, capacity, departure and scoped signalling, then implement server/index.ts and server/signalling.ts.
- [x] Implement browser media lifecycle, deterministic peer negotiation, queued ICE and cleanup in src/media.ts and src/meeting.ts. Verify with actual browser peers using synthetic tracks.
- [x] Build pre-join, meeting tiles/controls and ended views with responsive brand styling.
- [x] Document local and temporary HTTPS tests, optional TURN and limitations in README.md and TESTING.md.
- [ ] Run lint, typecheck, room tests, browser tests and production build. Inspect responsive screenshots; review lifecycle/security code and resolve findings.

## Verification commands

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:browser`.
